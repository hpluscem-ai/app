# 서버 이전 전 통합 QA — 2026-09-27

네이티브 원본 `.env.local`은 변경하지 않았다. 연결 문제를 우회해 검증을 계속하기 위해 환경 파일을 제외한 임시 앱 복사본과 프로세스 환경변수만 사용했다. 이 환경 차이는 아래 문제 목록에 남겼다.

단일 연결 조건의 실패 2개는 별도 미해결 검증 기록이다. `change-password`의 expired-token 검증은 400 대신 204였고, fixture가 Node의 현재 시각을 만료 시각으로 넣는 반면 서버는 DB `CURRENT_TIMESTAMP`와 비교하므로 시각 경계가 원인 후보다. `stations`의 부모 변경 실패 주입은 500 대신 401로 인증 단계에서 끝나 실제 롤백 검사에 도달하지 못했다. 해당 순간의 세션 사전 상태가 없어 원인은 확정하지 못했다. 두 케이스만 같은 풀 조건에서 각각 다시 실행하면 통과했다. 테스트·제품 코드는 수정하지 않았으며, 이 결과를 단일 연결 전체 회귀 통과나 새 제품 결함으로 해석하지 않는다.

QA-12의 SDK 57 `File.copy()`는 `Promise<void>`이고, 아직 없거나 읽을 수 없는 파일의 `size`는 0이다. 현재 코드는 이 0과 50MiB 초과를 같은 오류로 표시한다. [Expo SDK 57 FileSystem 공식 문서](https://docs.expo.dev/versions/v57.0.0/sdk/filesystem/). 초기 신청·재등록의 같은 준비 helper와 2장 모드에 적용되는 코드 경로다. 10MiB 또는 4096px를 넘는 변환 경로는 별도이며, 사진 내려받기·캐시 삭제에는 같은 copy 호출이 없다. 기존 단위 테스트의 copy 대역은 동기여서 이 경쟁을 검증하지 못했다. 이 QA에서는 수정하지 않았고, 실제 URI 접근 실패가 함께 있는지는 별도 확인 대상이다.

QA-13은 QA-12와 다른 단계다. 변환 대상 사진은 copy 분기를 사용하지 않아도 multipart 직렬화에서 막히며, 두 경로가 공통으로 사용하는 신규 신청·재등록 요청에 영향을 준다. Android logcat은 실제 기기 런타임 증거이고, 별도 `convertFormData` 재현은 설치된 Expo 57 소스를 Node에서 실행한 코드 수준의 확인이다. 웹의 Blob 전송은 정상이며 기존 API 클라이언트 테스트가 이 native descriptor 조합을 검증하지 않았다. 임시 QA 복사본에 예외 이름·문구만 기록해 실제 오류를 확인한 뒤 해당 진단 코드를 제거했다. 원본 제품 코드는 수정하지 않았다.

## 기존 정책과 다른 문구·호스팅 제약

- 회원탈퇴 확인창은 마일리지를 포함한 데이터 삭제를 말하지만, 승인 정책과 서버는 회원 원문·영수·정산 이력을 보존한다. 실제 확인창에서 재확인했고 변경하지 않았다.

- 앱 사진 50MiB, 서버 정산 파일 5MiB 허용과 Vercel 함수의 4.5MB 요청 제한은 별개다. 실제 로컬 API는 4.5MB보다 큰 사진 업로드를 통과했지만, 운영 Vercel 제한이 해제됐다는 뜻은 아니다. [Vercel 공식 제한](https://vercel.com/docs/functions/limitations#request-body-size).
- 운영 공개 소속 조회가 정상 200 `[]`를 반환하며 가입 화면은 `선택 가능한 소속이 없습니다.`로 가입을 막는다. 초기 운영 데이터 준비 문제이며 API 연결 실패로 분류하지 않는다.
- IAB에서 로그아웃 뒤 로그인 입력값이 복원되는 현상을 관측했다. 앱의 비밀번호 영속 저장 경로는 없으며, 후속 Chrome에서도 방금 사용한 QA 계정과 다른 저장 계정의 자동완성을 확인했다. 해당 저장 자격증명은 제출하지 않았다. 브라우저 자동완성/폼 복원과 구분해야 하므로 앱 보안 결함으로 확정하지 않았다.
- Android 지도 표면과 Google 표시는 보였지만 도로 타일·마커는 확인하지 못했다. Maps 키 오류를 확정할 로그는 없어 환경·네트워크·지도 범위 문제와 구분할 후속 검증이 필요하다. 사진 조회의 Expo `Response.blob()` 안내는 실제 사진 표시/확대가 성공했으므로 개발 경고로만 기록한다.
- 어드민 푸터에는 `홍길동`, `010-0000-0000` 등 예시 운영 정보가 남아 있다. 실제 화면에서 확인했으며 운영 정보 확정 대상으로 남긴다.
- 서버 프로세스 강제 종료 뒤 불확실 원본 객체 1개·업로드 시도 1개가 남고, 재기동 후 재시도는 정상 신청과 새 원본/정규화 객체를 만들었다. 불확실 객체는 자동 정리하지 않는 승인 정책과 일치하므로 결함으로 세지 않는다. 운영자가 보존된 후보 키로 수동 확인해야 하는 제약은 유지된다.

이전 운영 API 500은 2026-09-27 04:22 KST 재확인에서 재현되지 않았다. 기본 API·소속 조회·Swagger는 200, 인증 없는 기사/관리자 세션 조회는 401이었다. 이 QA에서 운영 설정이나 배포를 변경하지 않았으므로 회복 원인은 확정하지 않는다.

## OCR 전송 사진 해상도 축소 — 2026-09-27
